# 🍇 VineGuard — AI-скаутер виноградників

PWA-застосунок, який через камеру смартфона аналізує листки винограду в реальному часі та видає професійні рекомендації.

## Швидкий старт

```bash
cd grape-scanner
cp .env.local.example .env.local
# Вставте ваш OpenAI API ключ у .env.local
npm run dev
```

Відкрийте `http://localhost:3000` на телефоні (або в емуляторі).

## Функції

- 📷 Живий сканер з авто-захопленням кожні 3с
- 🔄 Перемикання фронтальної/тилової камери
- 🧠 GPT-4o аналізує: хвороби, шкідників, дефіцит елементів, опіки
- 📋 Діагноз + рівень загрози + причини + препарати/дози + профілактика
- 🌐 PWA-ready для встановлення на екран телефону

## Деплой (Vercel)

```bash
vercel --prod
# Додати змінну оточення: OPENAI_API_KEY
```

## Технології

Next.js 14, TypeScript, Tailwind CSS, OpenAI GPT-4o Vision
